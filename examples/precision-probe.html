GPU precision probe

Checks whether this GPU's shader compiler keeps the double-float (pairs of float32) arithmetic that the root solve relies on. Each building block runs on 16,384 inputs and is compared with exact results computed in JavaScript (float64). shipped is the code in the production shader; the other columns are the same algorithms with different guards against compiler simplification. A value near 1e-14 or below means the double-float step works; near 1e-7 means it has collapsed to plain float32.
